# fcc-html-repo

## About
This repository contains excercises and mini-projects from the FreeCodeCamp HTML course.
Focus is on learning HTML step by step, following FreeCodeCamp's structure.

## Course structure
1. Basic HTML
2. Semantic HTML
3. Forms and Tables
4. Accessibility

## Commit strategy
Each commit corresponds to a completed excercise or mini-project.
This helps track progress and practise Git skills.
